## 1. Backup do parser (antes de qualquer mudança)

- **Tag no git:** `parser-backup-2026-11-03`, no commit `d49da2b`, com push
  para o GitHub. Inclui o parser e o código da app que lê números.
- **Cópia da pasta:** `backups/parse-receipt-2026-11-03/`, igual à
  `supabase/functions/parse-receipt` (confirmado com `diff -r`). Fica fora do
  deploy, porque o deploy só envia `supabase/functions/`.
- **Versão em produção:** `parse-receipt` **v59**, publicada a 2026-11-02 às
  22:43 UTC.
- **Para voltar a ela:** o Supabase não volta a uma versão antiga pelo número.
  Faz-se um deploy novo com o código guardado:
  ```
  git checkout parser-backup-2026-11-03 -- supabase/functions/parse-receipt
  npx supabase functions deploy parse-receipt --project-ref eoevulbjtpidskzoyfno
  ```
  Ou, sem usar o git, a partir da cópia:
  ```
  rm -rf supabase/functions/parse-receipt && cp -r backups/parse-receipt-2026-11-03 supabase/functions/parse-receipt
  npx supabase functions deploy parse-receipt --project-ref eoevulbjtpidskzoyfno
  ```

  - São as 12 faturas com Vision guardado (`__fixtures__`) e as 2 fotos de
